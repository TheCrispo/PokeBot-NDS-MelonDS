# Repository package

This package is prepared from the confirmed working PokéBot D/P/Pt source.

It contains the project files intended to be copied into a GitHub fork of the original PokéBot NDS repository.

Included:
- PokéBot Lua source
- Dashboard source/assets
- `lua/modules/socket/core.dll` required by the Windows dashboard
- Original PokéBot MIT `LICENSE`
- LuaSocket MIT license notice
- `MODIFICATIONS.md`

Not included:
- Pokémon ROMs
- Nintendo BIOS/firmware
- Save files
